# lab5
Условие задачи

Садовод-робот сажает семена в лунки. Лунка считается «идеальной» для посадки, если все три измеренных параметра кислотности почвы (a, b, c) кратны трём. Определить, является ли лунка идеальной.

1. Алгоритм и блок-схема
Алгоритм
Начало
Ввести исходные данные:
a — первый параметр кислотности почвы;
b — второй параметр кислотности почвы;
c — третий параметр кислотности почвы.
Проверить условие идеальной лунки:
если a % 3 == 0 и b % 3 == 0 и c % 3 == 0, вывести сообщение «Почва идеальная», вернуть код 0 и перейти к шагу 5.
Иначе вывести сообщение «Почва не идеальная» и вернуть код 1.
Конец

2. Реализация программы
c
#define _CRT_SECURE_NO_DEPRECATE
#include <stdio.h>
#include <locale.h>
int main() {

	int a, b, c;
	setlocale(LC_ALL, "RUS");

	printf("Введите 1 измеренный параметр кислотности почвы\n");
	scanf("%d", &a);

	printf("Введите 2 измеренный параметр кислотности почвы\n");
	scanf("%d", &b);

	printf("Введите 3 измеренный параметр кислотности почвы\n");
	scanf("%d", &c);

	if (a % 3 == 0 && b % 3 == 0 && c % 3 == 0) {
		printf("Почва идеальная");
		return 0;
	}
	else {
		printf("Почва не идеальная");
		return 1;
	}

}
