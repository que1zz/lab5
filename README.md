# lab5
## Условие задачи

Садовод-робот сажает семена в лунки. Лунка считается «идеальной» для посадки, если все три измеренных параметра кислотности почвы (**A**, **B**, **C**) кратны трём. Запишите условие для «идеальной» лунки и определите, является ли лунка идеальной.

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало**
2. Задать исходные данные:
  - `a` — первый измеренный параметр кислотности почвы.
  - `b` — второй измеренный параметр кислотности почвы.
  - `c` — третий измеренный параметр кислотности почвы.
3. Проверить условие «идеальной» лунки:
  - если `a % 3 == 0` и `b % 3 == 0` и `c % 3 == 0` — все три параметра кратны трём.
4. Если условие выполнено:
  - вывести сообщение «Почва идеальная»;
  - вернуть код завершения `0`.
5. Если условие не выполнено:
  - вывести сообщение «Почва не идеальная»;
  - вернуть код завершения `1`.
6. **Конец**
